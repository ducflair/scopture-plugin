# Year 0: Foundations & Architecture Design (/docs/roadmap/y0)



## Foundation Stage [#foundation-stage]

* **Precision Requirements**: Define precision rules, physical coordinate spaces, and element primitives.
* **Canvas Infrastructure**: Establish viewport management, snapping rules, and geometric coordinate math.
* **Initial SDK Prototyping**: Begin development of core TypeScript and Python libraries for parsing and generating drawing structures.
* **Architecture Design**: Create open architecture specs and visual Figma design diagrams.
