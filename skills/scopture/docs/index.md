> An engineering model open for interactive inspection in Scopture, , representing physical-engineering work from the <a href="http://oresat.org/satellites/oresat0-5" target="_blank" rel="noopener noreferrer" className="underline hover:text-fd-foreground">OreSat 0.5</a> project.

Scopture is a desktop and cloud workspace for reviewing physical-engineering work before it is executed. It brings drawings, interactive models, references, issues, decisions, and revision history into one shared context, so the reasoning behind a design remains available as the design changes.

The desktop app supports solo offline editing with real `.duc` files and local Python execution. Authenticated paid cloud workspaces support remote editing and compute with the required permissions. Free browser access and local files opened on mobile are read-only.

Teams continue to create source material in the CAD, BIM, analysis, and authoring tools suited to their disciplines. Scopture provides the review and decision-traceability layer between that work and physical execution.
