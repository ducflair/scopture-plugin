# What Is Scopture? (/docs/get-started/what-is-scopture)



Scopture connects engineering outputs on an infinite canvas, makes them reviewable in two and three dimensions, and records what was requested, questioned, decided, and changed.

## What Scopture Keeps Together [#what-scopture-keeps-together]

| Project context   | Purpose                                                                                       |
| ----------------- | --------------------------------------------------------------------------------------------- |
| **Artifacts**     | Drawings, interactive models, PDFs, documents, images, references, and reusable blocks        |
| **Intent**        | The project charter, including objectives, requirements, constraints, stakeholders, and phase |
| **Review**        | Issues anchored to a canvas location, an element, or an exact point in a 3D model             |
| **Decisions**     | Outcomes and rationale linked back to the issues that informed them                           |
| **History**       | Checkpoints, incremental changes, external-file revisions, previews, and restoration          |
| **Collaboration** | Live presence, comments, assignments, controlled sharing, and review permissions              |

The result is a navigable record of the project state and the reasoning around it, rather than a folder of disconnected deliverables.

## Local and Remote Drawings [#local-and-remote-drawings]

Use a **remote drawing** when the work must be shared, reviewed in a browser, or edited with live collaborators. Cloud editing and compute require authentication, an entitled paid organization, and the relevant drawing permissions. Free browser access supports read-only public and community drawings.

Use a **local drawing in the desktop app** for solo offline editing. Scopture saves a real `.duc` file on disk, supports linked local assets, and runs Python locally. Mobile opens local folders and `.duc` files read-only, without local Python or AI. A local drawing can be moved to the cloud when its assets are available for upload.

See [Drawings, Sharing, and Export](/docs/concepts/drawings-sharing-and-export) for storage, recovery, and access details. The desktop app also includes a [command-line interface](/docs/automation/cli-tool).

## Product Boundary [#product-boundary]

Scopture does not replace the specialist tools used to author engineering geometry, run discipline-specific analysis, or manage construction and production. It is the decision-traceability layer between design creation and execution: the place where heterogeneous evidence can be assembled, examined, discussed, and approved without losing its relationships.

Continue with [Run a Design Review](/docs/get-started/design-review) to see how that context is used in practice.
